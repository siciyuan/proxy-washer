
# Proxy-Checker-Merger

一个基于 Python 异步协程与 FastAPI 构建的高效代理节点清洗与订阅聚合系统。支持本地网络真实连通性测试、多路 IPv6 探测、Clash 配置自动生成以及 SFTP 自动化部署。

## 📖 项目简介

在日常网络测试与节点管理中，直接从网络抓取或聚合的免费节点往往存在大量死链、假活节点，且由于服务器与本地网络环境的差异，云端测试可用的节点在本地往往无法连通。

本项目采用 **“云端聚合粗筛 + 本地环境细筛”** 的架构。云端负责接收大量节点池并生成基础订阅；本地脚本则利用真实的本地网络环境，通过高并发 TCPing 与 HTTP 探活，精准过滤出真实可用的节点，并自动推送回云端，最终生成一份高度纯净的 Clash 订阅。

## ✨ 核心特性

*   **高并发测活**：基于 `asyncio` 与 `aiohttp` 实现，采用协程并发，单机即可在数秒内完成上千节点的 TCPing/SSL 探活与 HTTP 真实请求测试。
*   **本地环境适配**：解决云端与本地网络环境不一致导致的“误杀”问题。本地脚本运行于物理机，结果更贴近实际使用体验。
*   **多路 IPv6 探测**：并发探测多个公共 DNS (Cloudflare / Google / Quad9)，避免单点故障导致 IPv6 节点被错误丢弃。
*   **自动化部署**：集成 `paramiko` 库，测速完成后通过 SFTP 自动同步至云端，并采用临时文件 (`tmp`) 与重命名机制，实现原子化替换，防止文件损坏。
*   **安全鉴权与防滥用**：管理接口采用 `SHA-256` 哈希鉴权验证；严格区分只读订阅接口与管理写操作接口，防止未授权操作。
*   **请求伪装 (可选)**：支持根路径反向代理，可将服务伪装成常规站点（如静态博客、信息查询页等），提升服务隐蔽性。

## 🏗️ 系统架构

1.  **云端服务端 (FastAPI)**：部署于服务器或容器，提供节点解析、Clash YAML 合并生成、总列表输出及最终订阅的只读分发。
2.  **本地清洗端 (Python 脚本)**：拉取云端总列表（或本地节点源），发起真实网络请求与 TCPing 进行清洗，生成精简版 YAML 并通过 SFTP 上传。
3.  **客户端**：直接订阅云端生成的 `/sub/cleaned` 接口，享受自动测速分组的纯净节点。

## 🚀 快速开始

### 1. 云端服务端部署

```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量 (推荐)
export PANEL_UUID="your_secret_uuid"
export ADMIN_PASSWORD="your_secure_password"

# 启动服务
python app.py
```

· 默认面板端口：20270
· 管理面板地址：http://ip:20270/panel/{PANEL_UUID}
· 总订阅接口：http://ip:20270/panel/{PANEL_UUID}/sub
· 纯净订阅接口：http://ip:20270/panel/{PANEL_UUID}/sub/cleaned

2. 本地清洗脚本运行

```bash
# 安装依赖
pip install aiohttp aiohttp-socks PyYAML paramiko tqdm

# 运行脚本
python local_cleaner.py
```

根据终端提示，输入订阅链接或本地文件路径，并配置 SFTP 连接信息。脚本将自动完成解析、测速、清洗及上传。
